1 Purpose

This notebook runs Borusyak imputation DiD models for one pre-specified, bounded AST sequence token band produced by run-py-6a. The wrapper passes one of the ten bands from 50-59 through 140-149 and renders this notebook independently for the full zero-inclusive panel and the conditional ratio-positive panel.

The notebook estimates the Heterogeneity RQ. The Primary RQ uses the separate minimum-threshold specification ast_sequence_token_count >= 50 with no upper bound and is not estimated here.

The notebook deliberately separates:

  1. Full repository-month occurrence and count outcomes.
  2. The conditional AGC event ratio among positive-event repository-months.
  3. Paper NCLOC and Python-snapshot NCLOC specifications.
  4. Full and parse-clean samples, selected through PARSE_EXCLUSION_MODE.
  5. The ten bounded AST sequence token bands, verified against input metadata.

For each band, the canonical arithmetic is:

  • function_change_events = agc_function_change_events + hwc_function_change_events
  • agc_function_change_event_ratio = agc_function_change_events / function_change_events

The ratio remains missing when the denominator is zero. Count outcomes use log1p() transformations. Repository-month activity outcomes log1p_commits and log1p_lines_added are retained and validated as common reference outcomes, but are not re-estimated separately in every band because they do not vary by AST sequence token band.

The two NCLOC variables are never included in the same first-stage formula. Lead/lag columns retained by run-py-5e are validation fields only; dynamic coefficients are requested from didimputation::did_imputation() using horizon = -6:6 and pretrends = -6:-2.

Regression guards carried over from the validated run-py-5f notebook are retained. Additional band-specific guards verify the label and inclusive / exclusive bounds, bounded-band specification, AGC/HWC partition, log1p transformations, zero-denominator ratio handling, and ratio bounds.

normalize_yyyymm <- function(x) {
  x <- as.character(x)
  x[x %in% c("", "NA", "NaN", "NULL", "None")] <- NA_character_
  x <- gsub("-", "", x)
  suppressWarnings(as.integer(x))
}

yyyymm_to_month_id <- function(x) {
  x <- as.integer(x)
  year <- x %/% 100L
  month <- x %% 100L
  out <- year * 12L + month
  out[is.na(x) | month < 1L | month > 12L] <- NA_integer_
  out
}

require_columns <- function(data, required, label) {
  missing <- setdiff(required, names(data))
  if (length(missing) > 0) {
    stop(label, " missing required columns: ", paste(missing, collapse = ", "))
  }
}

count_nonmissing <- function(data, column_name) {
  if (!(column_name %in% names(data))) {
    return(NA_integer_)
  }
  sum(!is.na(data[[column_name]]))
}

write_error_table <- function(errors, stage, output_path, metadata) {
  if (length(errors) == 0) {
    error_df <- data.frame(
      stage = character(),
      outcome = character(),
      error = character(),
      stringsAsFactors = FALSE
    )
  } else {
    error_df <- data.frame(
      stage = stage,
      outcome = names(errors),
      error = unlist(errors),
      row.names = NULL,
      stringsAsFactors = FALSE
    )
  }

  for (metadata_name in names(metadata)) {
    error_df[[metadata_name]] <- rep(
      as.character(metadata[[metadata_name]]),
      nrow(error_df)
    )
  }
  fwrite(error_df, output_path)
}

add_run_metadata <- function(data, metadata) {
  for (metadata_name in names(metadata)) {
    data[[metadata_name]] <- metadata[[metadata_name]]
  }
  data
}
