1 Purpose

This notebook estimates the effect of observed Cursor adoption on repository-month AI-generated-like code outcomes using the Borusyak et al. imputation difference-in-differences estimator.

The primary outcome is the proportion of scored top-level Python function and class blocks whose AST-based structural representations are classified as AI-generated-like. Function-only and class-only proportions are analyzed as robustness outcomes.

Two adjusted specifications are compared on the same complete-case sample for each outcome:

  1. Paper NCLOC specification: uses ncloc_paper from the frozen paper panel.
  2. Python snapshot NCLOC specification: uses ncloc_python_snapshot calculated from the exact exported historical Python snapshot.

The outcome captures structural patterns associated with AI-generated code. It does not establish the actual provenance of an individual block or identify which AI tool generated or assisted with it.

Because the outcomes are proportions, coefficients are reported in both proportion units and percentage points. They are not transformed with exp(beta) - 1.

3 Utility Functions

normalize_yyyymm <- function(x) {
  x <- as.character(x)
  x[x %in% c("", "NA", "NaN", "NULL", "None")] <- NA_character_
  x <- gsub("-", "", x)
  suppressWarnings(as.integer(x))
}

yyyymm_to_month_id <- function(x) {
  x <- as.integer(x)
  year <- x %/% 100L
  month <- x %% 100L

  out <- year * 12L + month
  out[is.na(x) | month < 1L | month > 12L] <- NA_integer_
  out
}

require_columns <- function(data, required, label) {
  missing <- setdiff(required, names(data))
  if (length(missing) > 0) {
    stop(label, " missing required columns: ", paste(missing, collapse = ", "))
  }
}

numeric_if_present <- function(data, columns) {
  for (column_name in intersect(columns, names(data))) {
    set(
      data,
      j = column_name,
      value = suppressWarnings(as.numeric(data[[column_name]]))
    )
  }

  invisible(data)
}

safe_ratio <- function(numerator, denominator) {
  out <- rep(NA_real_, length(denominator))
  valid <- !is.na(numerator) & !is.na(denominator) & denominator > 0
  out[valid] <- numerator[valid] / denominator[valid]
  out
}

empty_model_error_table <- function() {

    stringsAsFactors = FALSE

}

          panel = panel_label,
          specification = specification,
          outcome = outcome_var,
          model_type = "static",
          error = conditionMessage(e),
