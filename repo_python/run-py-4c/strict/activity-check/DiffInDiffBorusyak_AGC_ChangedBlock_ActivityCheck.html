1 Purpose

This debugging report checks whether the validated AGC changed-block panel can also reproduce the original development-activity outcomes using only:

  • monthly commits; and
  • monthly lines added.

The AGC changed-block columns are not used as outcomes in this report. The input panel is used because it preserves the strict matched repository-month sample and its original activity variables.

3 Helper Functions

normalize_yyyymm <- function(x) {
  text <- gsub("-", "", trimws(as.character(x)))
  text[text %in% c("", "NA", "NaN")] <- NA_character_
  suppressWarnings(as.integer(text))
}

yyyymm_to_month_id <- function(x) {
  year <- x %/% 100L
  month <- x %% 100L
  invalid <- is.na(x) | month < 1L | month > 12L
  result <- year * 12L + month
  result[invalid] <- NA_integer_
  result
}

require_columns <- function(data, columns, label) {
  missing <- setdiff(columns, names(data))
  if (length(missing) > 0L) {
    stop(label, " is missing required columns: ", paste(missing, collapse = ", "))
  }
}

extract_static_effect <- function(result, outcome_name, outcome_label, n_rows) {
  row <- result[result$term == "treat", , drop = FALSE]
  if (nrow(row) != 1L) {
    stop("Expected exactly one static treatment-effect row for ", outcome_name)
  }

  data.frame(
    outcome = outcome_name,
    outcome_label = outcome_label,
    term = "treat",
    estimate_log = row$estimate,
    std_error = row$std.error,
    conf_low_log = row$conf.low,
    conf_high_log = row$conf.high,
    percent_change = (exp(row$estimate) - 1) * 100,
    percent_conf_low = (exp(row$conf.low) - 1) * 100,
    percent_conf_high = (exp(row$conf.high) - 1) * 100,
    model_rows = n_rows,
    stringsAsFactors = FALSE
  )
}

extract_dynamic_effects <- function(result, outcome_name, outcome_label, n_rows) {
  rows <- result[result$term != "treat", , drop = FALSE]
  rows$event_time <- suppressWarnings(as.integer(as.character(rows$term)))
  rows <- rows[!is.na(rows$event_time) & rows$event_time >= -6L & rows$event_time <= 6L, ]

  data.frame(
    outcome = outcome_name,
    outcome_label = outcome_label,
    event_time = rows$event_time,
    estimate_log = rows$estimate,
    std_error = rows$std.error,
    conf_low_log = rows$conf.low,
    conf_high_log = rows$conf.high,
    percent_change = (exp(rows$estimate) - 1) * 100,
    percent_conf_low = (exp(rows$conf.low) - 1) * 100,
    percent_conf_high = (exp(rows$conf.high) - 1) * 100,
    is_significant = rows$conf.low > 0 | rows$conf.high < 0,
    model_rows = n_rows,
    stringsAsFactors = FALSE
  )
}

9 Interpretation

The activity outcomes are retained from the strict matched repository-month panel. They are separate from the AGC changed-block outcome:

  • commits measure monthly repository activity;
  • lines added measure monthly code-production volume; and
  • the AGC changed-block ratio measures the structural classification share among newly added or structurally modified top-level blocks.

A successful activity check does not validate the AGC treatment effect by itself. It verifies that the same strict panel still produces interpretable Cursor-adoption estimates for the original velocity outcomes.
